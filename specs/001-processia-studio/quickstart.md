# Reprise et démonstration

## 20 · Scénario de revue Kosmio et préparation du passage à Codex

### Jeu de démonstration proposé

Le processus « Réaliser un diagnostic IA » est un exemple de travail, à confirmer par Mathieu : préparer le dossier → conduire l’entretien → modéliser le fonctionnement → compléter les témoignages → identifier les opportunités → prioriser → restituer le diagnostic et la feuille de route. Ce parcours décrit une mission de Kosmio ; la cartographie du client est un objet distinct dans son dossier.

| Étape d’essai | Observation attendue |
|---|---|
| Préparer | Le consultant apporte trois sources synthétiques par MCP et obtient les points manquants. |
| Partager | Il choisit une première carte sans partager sa note privée. |
| Démarrer | Le responsable ouvre son lien, accepte le mode d’écoute et retrouve le contexte. |
| Parler | « Avant la restitution, je fais une revue des recommandations » ajoute une proposition locale. |
| Manipuler | Le responsable sélectionne la revue, change son rôle et ajoute un modèle de document. |
| Clarifier | Un second témoignage décrit une autre pratique ; l’application garde les deux périmètres ou signale un désaccord. |
| Diagnostiquer | Trois priorités maximum sont proposées avec sources, prérequis et essais. |
| Transmettre | Le rapport et la carte sont exportés depuis une version précise sans les notes privées. |

### Reprise par Codex

1. Lire `CONTEXT.md`, la constitution, `spec.md` et `clarifications.md`.
2. Confirmer les décisions nécessaires à la première tranche, puis compléter `research.md` et `plan.md` avec les choix réels et versions.
3. Examiner le modèle de données et les contrats ; mettre à jour les tâches et la matrice de traçabilité si un choix modifie le comportement.
4. Démarrer T001 avec un seul test public échouant, le faire passer et documenter le résultat.
5. Continuer par petites tranches ; conserver les états non commencé / en cours / vérifié dans le suivi.
6. Exécuter les contrôles appropriés avant de considérer chaque tranche terminée. Présenter la démonstration et les limites.

Les tâches de ce dossier sont toutes non commencées. Les tests décrits sont des cas de test à implémenter, et non des tests déjà exécutables. L’installation de Spec Kit, le choix du fournisseur IA, l’ouverture de services et le déploiement restent des travaux de la phase suivante.
