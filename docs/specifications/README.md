# Spécifications de ProcessIA

Le document de revue principal est `processia-specifications-v0.2.html`. Il est autonome et peut être ouvert hors ligne dans un navigateur. Le bouton Imprimer / PDF ouvre le dialogue d’impression et inclut les critères détaillés.

Les sources de spécification se trouvent dans `specs/001-processia-studio/` et la constitution dans `.specify/memory/constitution.md`. Toute évolution des exigences doit mettre à jour la traçabilité et la vue HTML avant une nouvelle revue.

Les contrôles du HTML ont vérifié la navigation, les liens internes, la recherche, les filtres, l’ouverture des critères, l’affichage bureau et mobile et la génération d’une impression. Les captures bureau, mobile et exigences ont été relues visuellement. Aucun test produit ProcessIA n’est présenté comme exécuté.

Le dossier suit la méthode et les modèles officiels de GitHub Spec Kit. Son CLI et ses commandes n’ont pas été installés ou exécutés pendant la rédaction. Le plan technique et la constitution restent proposés, à valider au début du développement.
